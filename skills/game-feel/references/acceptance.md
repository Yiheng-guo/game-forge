# game-feel: acceptance scenarios

1. A meaningful impact produces short synchronized feedback with input still responsive. Record the fixture, action, expected result and observed result.
2. Rapid overlapping impacts return to baseline and cannot freeze simulation. Record the fixture, action, expected result and observed result.
3. Reduced-motion mode removes shake and flashes without hiding hit confirmation. Record the fixture, action, expected result and observed result.

Run the smallest relevant scenario in the real engine/browser, then the neighboring lifecycle path.
For an existing project, compare before/after using the same fixture. A document validator or mocked API does not verify the engine behavior. Mark unavailable runtimes as untested; include the command or manual steps another developer can run.
