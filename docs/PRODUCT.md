# 造游：游戏创作工作台

面向希望验证玩法的产品经理、创作者与原型开发者。核心任务是将一个玩法描述推进为可操作的游戏，并在试玩后持续修改同一个项目。

## 核心流程

新建空白游戏或复制示例 → 描述玩法 → 真实模型生成完整游戏 → 语法与初始运行检查 → 隔离试玩 → 描述修改 → 保存新版本 → 比较或恢复旧版 → 分享独立游戏。

成功生成是代码和初始加载完成，不能代表玩法已被真人认可。真人验证应独立观察首次理解、操作困难、失败恢复与是否愿意再次游玩。

## 版本语义

一个项目包含对话、不可变版本列表和当前工作版本指针。试玩历史版不会删除最新版本；点击恢复会将后续修改起点指向该版本。每个新版本记录父版本，因此可以从旧版形成新的迭代方向。失败、取消、浏览器关闭和页面刷新不会覆盖已有游戏。

手动代码保存与 AI 修改都产生新版本。模型修改以当前选中的版本为上下文，并被要求保留无关玩法、内容与操作。保留效果必须在实际生成结果中验证，不能仅凭提示词保证。

## 交付范围

支持自包含浏览器 HTML / Canvas 2D 游戏。示例覆盖动作生存、轻经营与解谜。当前不承诺大型游戏、原生引擎工程、多人服务器、美术资源管线或在线多人协作。

生成服务在本机运行，使用当前用户自己的 Codex 登录。公网静态页面用于示例与独立分享，不提供公共模型额度。共享游戏不依赖创作者持续在线。
