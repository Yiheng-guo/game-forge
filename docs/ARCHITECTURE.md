# 架构与运行边界

前端是 React / Vite；本机服务是 Node.js / Express。生成适配器通过参数数组调用 `codex exec`，不拼接 shell 命令，不复制登录令牌到应用配置、浏览器或远端。

## 生成任务

每次生成记录任务 ID、所属项目、所选基础版本和状态。状态依实际执行阶段变化：排队、运行、检查、一次修复、完成、失败或取消；没有虚构百分比。单服务同一时间执行一个生成任务，避免并发修改与无意消耗额度。任务最长八分钟，取消向生成进程发送终止信号。

模型输入由当前用户要求、所选版本的完整游戏和实际加载的七个技能正文组成。结果采用 JSON schema；HTML 通过内容与语法验证后，在禁止联网的独立浏览器 iframe 中做初始加载检查。仅成功结果进入版本库。

初始加载检查无法证明完整玩法正确。预览捕获实际运行错误，可由用户发起下一轮修复。自动修复最多一次，以避免无限调用。没有可用浏览器时检查状态为空，界面不能将其称为运行检查通过。

## 项目存储

项目使用随机 UUID，版本身份由存储层分配，模型返回值不能覆盖 ID、版本号和来源。文件持久化按序执行，采用临时文件与原子替换，并保留上一份备份。数据损坏时报错，禁止悄悄重置或覆盖。当前单进程设计不支持多个实例共享同一目录。

## 预览隔离

iframe 仅允许脚本执行，没有同源、弹窗、导航或表单权限。CSP 放在模型内容之前，限制网络、字体、外部脚本、嵌入文档及表单；宿主只处理来自当前 iframe 且符合消息结构的运行错误。隔离减少宿主访问风险，不是防止恶意耗尽 CPU 的完整资源容器。

本机 API 拒绝不匹配的 Host、Origin 和跨站请求，受保护接口需要进程随机令牌。服务只绑定回环地址。连接状态表示 Codex 登录检查成功，不承诺模型网络与账号额度始终可用。

## 分享

选定版本的游戏、标题、目标与操作说明压缩后放在 URL fragment。静态播放器在浏览器内解压并放入同样的隔离 iframe；聊天和账号状态不进入分享对象。限制压缩载荷和解压缓冲大小，非法内容拒绝打开。URL 超长时引导使用自包含 HTML 下载。

公网托管只发布前端与示例，不发布 `.data/`、本机文件路径、临时模型输出或账号凭据。
